📖 Guía del Visor

🗺️ Navegación en el Mapa

  • Zoom: Rueda del ratón o botones +/-
  • Mover: Desliza el dedo o clic y arrastrar
  • Ubicación GPS: Botón 📍 en controles del mapa
  • Medición: Activar desde menú → Herramientas → Medición

🧭 Navegación a Árbol

  • Seleccione Navegar a Árbol en el menú
  • Elija el expediente y el árbol destino
  • La flecha le guiará con GPS en tiempo real
  • También puede navegar directamente desde el popup del árbol

⚙️ Cambiar Fuente de Datos

  • Acceda a Fuente de Datos desde el menú
  • Ingrese el ID del Google Sheet con los datos de árboles
  • Guarde y recargue para ver los nuevos datos
  • El formato del ID: 1ABC...XYZ

🌳 Simbología

  • ● Púrpura: Aprobado
  • ● Rojo: Denegado
  • ● Amarillo: Sin definir

📋 Formato de Google Sheet

  • Columnas requeridas: X (Este CRTM05), Y (Norte CRTM05)
  • Columnas opcionales: Expediente, Estado, Numero/ID
  • El Sheet debe ser público o compartido (ver como lector)
  • Sistema de coordenadas: CR-SIRGAS / CRTM05

⚙️ Fuente de Datos

Configura el Google Sheet con los datos de árboles y permisos

📊 Google Sheet de Datos

Ingrese el ID del Google Sheet que contiene los datos de árboles (pestaña principal, GID 0).

El ID se encuentra en la URL del Sheet: docs.google.com/spreadsheets/d/[ID]/edit

📑 Pestaña del Sheet (GID)

Si los datos están en una pestaña específica, ingrese su GID (número al final de la URL: #gid=XXXX).

📋 Webhook de Actividad (opcional)

URL de Google Apps Script para registrar el uso de la herramienta. Dejar vacío para desactivar.
